# Nauka Pytona i podstaw automatyzacji testów

Nic ciekawego, po prostu nauka od podstaw

## Co tu jest
- Podstawy pytona: warunki, pętle, funkcje, obsługa błędów
- Unit testy w pytest z parametryzacją

## How to run tests
```
python -m pip install -r requirements.txt
python -m pytest -v
```
